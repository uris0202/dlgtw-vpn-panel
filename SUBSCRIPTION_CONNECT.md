# Подключение единой подписки из личного кабинета

## Изменения

- В кабинете клиента появилась кнопка «Открыть в v2raytun».
- Кнопка использует напрямую `v2raytun://import/{subscription_link}` из официальной документации: https://docs.v2raytun.com/deep-link.
- QR-код и копирование содержат прежний HTTPS-адрес единой подписки. Подпись адреса не меняется.
- Ссылка не отправляется сторонним сайтам-посредникам. Страница загрузки приложения открывается без адреса подписки и без Referer.
- Если копирование запрещено браузером, используется резервное копирование. Если оно тоже не сработало, показывается ошибка.
- Настройка скрытия прямых VLESS-ссылок сохранена. Права доступа, оплаченные направления и срок подписки не меняются.
- На узких экранах кнопка заказа переносится на две строки и больше не расширяет форму продления за границы блока.

## Установка на сервере

Загрузите `subscription-connect-20261103.zip` в `/root`. Сначала сохраните прежние файлы, затем распакуйте обновление:

```sh
cd ~/vpnpanel &&
mkdir -p ~/vpnpanel-backups &&
umask 077 &&
tar -czf ~/vpnpanel-backups/pre-subscription-connect-$(date +%Y%m%d-%H%M%S).tar.gz \
  frontend/app/account frontend/components frontend/lib frontend/tests frontend/package.json frontend/package-lock.json &&
unzip -o ~/subscription-connect-20261103.zip -d ~/vpnpanel &&
sh scripts/install-subscription-connect.sh
```

Установщик дополнительно сохраняет проверенный список содержимого дампа PostgreSQL и прежний Docker-образ сайта в `/root/vpnpanel-backups/subscription-connect-ДАТА-ВРЕМЯ`. Проверка дампа здесь — `pg_restore --list`, не тестовое восстановление базы.

Затем собирает frontend, запускает его тесты и только после успеха пересоздаёт frontend. Backend, Caddy, HAProxy, монитор и VPN-серверы не перезапускаются. Возможна короткая пауза сайта при пересоздании frontend. Миграций и новых зависимостей нет.

## Проверка

1. На Android откройте кабинет клиента в браузере. Установленный v2raytun должен предложить импорт после нажатия «Открыть в v2raytun».
2. Подтвердите импорт в приложении и проверьте оплаченные направления. Кнопка открывает импорт, но не включает VPN автоматически.
3. Проверьте копирование и QR-код. В обоих случаях используется единая подписка, не прямая серверная ссылка.
4. Когда прямые ссылки скрыты в настройках, отдельные серверные QR-коды и VLESS-ссылки не должны появиться.
5. Проверьте новости, продление и публичную страницу `/status`.

Браузер не определяет надёжно, установлено ли приложение. Если оно не открывается, доступна ссылка «Скачать v2raytun», а также копирование и QR-код. Нативный импорт нужно проверить на настоящем Android: проверка страницы на компьютере не доказывает запуск приложения.

## Выполненные проверки

- Локально: 251 backend-тест, включая проверки установщика и настоящего Xray-движка; без ошибок и пропусков в настроенном окружении.
- 29 frontend-тестов и production-сборка Next.js прошли.
- Playwright: кабинет на ширинах 1440, 1280, 768, 390 и 320 px; скрытые/видимые прямые ссылки, истёкший доступ, ожидание оплаты, неверный адрес, вход через сессию и персональную ссылку.
- Проверены обычное и резервное копирование, сообщение об отказе, отсутствие автоматического открытия приложения и сохранение URL в нативной ссылке. В тесте запуск нативного обработчика намеренно перехвачен.
- Пиксели QR-кода совпадают с QR-матрицей исходной HTTPS-подписки. Проверены скриншоты и отсутствие обрезанных элементов формы.
- Повторно проверены публичный статус и административная карточка клиента на четырёх размерах экрана.
- Docker локально недоступен. Реальную Docker-сборку и запуск frontend-тестов выполнит установщик на сервере перед заменой контейнера.

## Откат только работающего сайта

Возьмите точный каталог резервной копии из вывода установщика:

```sh
cd ~/vpnpanel
backup=/root/vpnpanel-backups/subscription-connect-ДАТА-ВРЕМЯ
docker image tag "$(cat "$backup/frontend-image-id")" "$(cat "$backup/frontend-image-name")" &&
docker compose up -d --no-build --no-deps --force-recreate --wait --wait-timeout 180 frontend
```

Это возвращает прежний работающий Docker-образ. Чтобы последующая сборка не вернула обновление, отдельно восстановите код frontend из архива `pre-subscription-connect-…tar.gz`. Базу данных откатывать не требуется.

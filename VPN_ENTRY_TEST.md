# Проверка нового входного сервера без переноса сайта

Текущий сервер сайта и VPN-вход: `139.100.235.247`.
Новая тестовая машина: `139.100.230.76`.
Этот тест использует IPv4. Публичного IPv6 на новой машине пока нет.

## Что будет проверяться

```text
Обычный профиль: Android -> старый вход -> выбранный зарубежный сервер -> интернет
Копия профиля:   Android -> новый вход  -> тот же зарубежный сервер     -> интернет
```

Временный HAProxy на новой машине повторит существующие направления и номера портов.
UUID, ключи, SNI, REALITY, трафик и срок подписки используются из копии вашего профиля.
Новых клиентов, заказов и серверов в БД панели не создаётся.
В рабочую подписку тестовый адрес не добавляется.

Тестовый набор содержит только IP, порты и служебные ID маршрутов. Пароли 3X-UI,
JWT, UUID и токены подписок в него не копируются. Не отправляйте персональную VLESS-ссылку в чат.

Тест автоматически заканчивается через 600 секунд после запуска входа.
Ctrl+C завершает его раньше. Отдельный процесс `timeout` ограничивает время работы HAProxy
даже если управляющий Python-процесс аварийно завершится.
Рабочие HAProxy, DNS, firewall, Docker Compose и процессы Xray не изменяются.
Проверка IP интерфейса не даст случайно запустить тест на старой машине.

## 1. Подготовить на СТАРОМ сервере 139.100.235.247

Загрузите `vpn-entry-test-20261031.zip` в `/root` старого сервера.
Архив содержит только новые файлы; пересборка приложения и миграции не нужны.

```sh
(
set -e
cd ~/vpnpanel
unzip -o ~/vpn-entry-test-20261031.zip -d ~/vpnpanel
python3 scripts/vpn-entry-test.py prepare --entry-ip 139.100.230.76 --output ~/vpnpanel-entry-test-20261031
scp -r ~/vpnpanel-entry-test-20261031 root@139.100.230.76:/root/
)
```

Вход по SSH на новую машину должен быть разрешён. Если подключаетесь впервые,
сверьте отпечаток SSH-ключа с новой машиной через консоль Selectel. Пароль вводится
только в терминале SSH, не в чате и не на странице замера.

Скрипт считывает актуальный `relay/routes.json` старого сервера и не изменяет его.
Папка результата не должна существовать: повторная подготовка с тем же именем
остановится, а не перезапишет предыдущий набор. Для нового набора выберите другое имя папки.

## 2. Запустить на НОВОМ сервере 139.100.230.76

Подключитесь к новой машине отдельным SSH-сеансом. На ней выполните:

```sh
apt-get update
apt-get install -y --no-install-recommends haproxy
python3 ~/vpnpanel-entry-test-20261031/vpn-entry-test.py run
```

Установка пакета может запустить его штатную службу с конфигурацией дистрибутива.
Наш тест использует отдельный процесс и отдельный файл; системную конфигурацию HAProxy не заменяет.
Не закрывайте SSH-сеанс до завершения проверки. Скрипт работает на переднем плане.

Он проверит IP машины, отсутствие занятых тестовых портов и синтаксис HAProxy.
Затем выведет результаты проб TCP из новой машины к зарубежным направлениям.
`connected: false` означает проблему с соответствующим маршрутом/портом; работа остальных
направлений всё равно может быть проверена. Успешная TCP-проба ещё не доказывает работу VLESS.

Обычно тесту нужны TCP-порты `24443`, `24444`, `24445` и `18080` именно на новой машине.
Точные VPN-порты берутся из сохранённых маршрутов и выводятся при подготовке.
Если группы безопасности Selectel или UFW блокируют входящие подключения,
разрешите эти порты на новой машине только на время проверки, по возможности
ограничив доступ вашим клиентским IP. Скрипт сам правила firewall не меняет.
Не отключайте firewall целиком и не меняйте доступ SSH.

## 3. Подключиться из v2rayTun на Android

1. Обновите обычную подписку и выберите своё рабочее подключение, например Germany.
2. Сделайте отдельную копию профиля. Если приложение не предлагает дублирование,
   экспортируйте только свой профиль и импортируйте его как отдельный ручной профиль.
3. Назовите копию, например `Germany TEST`.
4. В копии замените только адрес сервера с `vpn.dlgtw.ru` на `139.100.230.76`.
   Порт оставьте прежним. SNI/Server name, UUID, Public key, Short ID, flow и fingerprint не меняйте.
5. Не редактируйте исходный профиль или URL подписки. При автообновлении подписки
   ручная тестовая копия не должна быть частью обновляемого списка.

Доступные команды редактирования зависят от версии v2rayTun. Если адрес копии
не удаётся изменить, пришлите скриншот её настроек, скрыв UUID и персональные ссылки.
Проверяйте через свою учётную запись: трафик теста учитывается на зарубежном сервере как обычный VPN-трафик.
Не используйте одновременно исходный профиль и копию на разных устройствах, если у клиента есть ограничение IP.

## 4. Сравнить загрузку

В Android подключите сначала ОБЫЧНЫЙ профиль. В Chrome вручную откройте:

```text
http://139.100.230.76:18080/
```

Это временная диагностическая страница, а не новая панель. Она работает по HTTP:
пароли и персональные ссылки на ней вводить не нужно. Публично её не распространяйте.

Нажмите «Проверить» и запишите результат. Затем выберите `Germany TEST` в v2rayTun,
вернитесь в браузер и повторите замер. Для сравнения используйте одну и ту же сеть
Wi-Fi/мобильного оператора, один зарубежный сервер и выполняйте замеры по очереди.
Если настроен раздельный VPN, браузер должен идти через VPN, а не в исключение.

Страница показывает фактический IP выхода и скачивает до примерно 32 МиБ за один замер,
прерывая загрузку через 20 секунд. Один замер может занять до примерно 26 секунд с проверкой IP.
Скорость — Мбит/с, не мегабайты в секунду. Частичные и отменённые загрузки не засчитываются.
Одно сравнение двух входов расходует примерно до 64 МиБ полезных данных плюс накладные расходы.
На очень медленном канале полный 32-МиБ замер может не уложиться в лимит: это не доказательство неисправности VPN.

Если IP выхода совпадает с сохранённым адресом зарубежного узла, страница отметит это.
Другой IP может означать обход VPN браузером, другой NAT-адрес или IPv6-выход узла;
такой результат нельзя автоматически считать проверкой нужного VPN-маршрута.
В обоих сравнениях должен использоваться один и тот же ожидаемый зарубежный выход.

Загрузка и IP проверяются через [Cloudflare Speedtest](https://github.com/cloudflare/speedtest).
Это короткий HTTP-замер всей цепочки, а не гарантированная максимальная пропускная способность сервера.
Результат зависит также от Android, Wi-Fi/оператора, зарубежного узла, его нагрузки и маршрута до Cloudflare.
Cloudflare может выбрать разные узлы обслуживания; единичный результат не повод переносить рабочую систему.
При блокировке внешнего сервиса замера страница покажет ошибку — это само по себе не доказывает поломку VPN.

Для предварительного сравнения достаточно одного-двух замеров каждого входа.
Пришлите IP выхода и результаты «старый/новый» для одного направления.

## 5. Завершить

На новой машине нажмите Ctrl+C или дождитесь окончания 10 минут.
Скрипт остановит только созданные им временные процессы и освободит тестовые порты.
После этого `Germany TEST` перестанет подключаться — это ожидаемо.
Выберите обычный профиль и удалите ручные тестовые копии.
Если добавляли временные правила firewall, удалите только эти правила.

Для повторной сессии на новой машине можно снова выполнить `python3 .../vpn-entry-test.py run`.
Если изменились зарубежные маршруты, сначала подготовьте свежий набор на старой машине.
Не меняйте DNS и не переносите сайт по результатам одного замера.

# Онлайн-клиенты на сайте

В разделе **Клиенты** на выбранном VPN-сервере теперь видно конкретные профили,
которые 3X-UI считает онлайн. Переписывания проекта и новых API-маршрутов нет.

## В интерфейсе

- «Доступ» показывает, разрешён ли клиенту доступ: «Активен» / «Отключен».
- «Подключение» отдельно показывает «Онлайн», «Не в сети» или «Нет данных».
- У не находящегося онлайн клиента показана последняя активность, если её
  вернул 3X-UI. Отсутствующая дата не превращается в ложную дату 1970 года.
- Фильтр «Все подключения → Онлайн» оставляет только подключённые профили.
  Он сочетается с поиском, фильтрами группы и разрешённого доступа.
- На телефоне эти же данные видны в карточках клиентов.
- Автообновление включено по умолчанию: раз в 30 секунд, пока вкладка видна.
  Его можно выключить чекбоксом. При возвращении на видимую вкладку выполняется
  обновление, если другой запрос ещё не идёт.
- Во время создания/редактирования клиента автообновление приостанавливается,
  чтобы не сбрасывать введённые данные. Обычные создание, изменение, удаление,
  QR, ссылки и выдача доступа в ЛК остаются на месте.
- Фоновое обновление не перерисовывает страницу через полноэкранный загрузчик
  и не запрашивает заново тарифы, настройки и список серверов.

При ошибке обновления последние данные клиентов сохраняются, но сведения
об онлайн-состоянии помечаются «Нет данных», а не выдаются за актуальные.
Ошибка отображается отдельно. Кнопка «Обновить» остаётся доступна.

## Источник данных

Статус берётся из `summary.online` существующего ответа 3X-UI. Это список
идентификаторов/email клиентов, а не догадка по флагу «Активен», трафику или ping.
Имена-псевдонимы без `@` поддерживаются. Идентификаторы сравниваются точно:
разные записи `Nick` и `nick` не смешиваются. [API клиентов 3X-UI](https://docs.sanaei.dev/docs/reference/api/clients/)

Ответ существующего `GET /clients/{server_id}` дополнен:

- `clients[].online`: `true`, `false` или `null` при неизвестном состоянии;
- `online_available`: предоставил ли 3X-UI распознаваемый список онлайн;
- `online_checked_at`: время получения списка в миллисекундах Unix;
- `truncated`: удалось ли загрузить полный список клиентов.

Прежние поля ответа сохранены. Список остаётся доступен только администратору.
Ответ помечен `Cache-Control: private, no-store`.

Поскольку 3X-UI ограничивает страницу 200 записями, список дочитывается постранично,
чтобы онлайн-клиенты после первой страницы не пропадали из таблицы.
Есть ограничение 100 страниц на запрос. Если сервер вернул неполные/повторяющиеся
страницы или лимит достигнут, интерфейс явно предупреждает о неполном списке.

Это снимок последних данных 3X-UI: его собственное обновление может задерживаться.
Это не доказательство мгновенного физического подключения устройства, количества
устройств или личности человека. Один профиль может использоваться несколькими
устройствами. Статус относится только к выбранному VPN-серверу, а не ко всем
серверам клиента сразу. Новые IP-адреса или данные посещённых сайтов не собираются.

## Установка

Загрузите `online-clients-20261102.zip` в `/root/` рабочего сервера сайта:

```sh
cd ~/vpnpanel &&
mkdir -p ~/vpnpanel-backups &&
umask 077 &&
tar --exclude='./.git' --exclude='./frontend/node_modules' \
    --exclude='./frontend/.next' --exclude='./backups' \
    --exclude='./relay/control/*.sock' \
    -czf ~/vpnpanel-backups/pre-online-clients-$(date +%Y%m%d-%H%M%S).tar.gz . &&
unzip -o ~/online-clients-20261102.zip -d ~/vpnpanel &&
sh scripts/install-online-clients.sh
```

Резервная копия проекта включает `.env`: не публикуйте её. Установщик дополнительно
сохраняет PostgreSQL dump и проверяет оглавление через `pg_restore --list`.
Это не пробное восстановление базы. Сначала собираются backend/frontend
и выполняются оба набора тестов; при ошибке до этой точки контейнеры не заменяются.

После проверок пересоздаются backend и frontend, затем перезапускается Caddy.
Панель в это время кратковременно недоступна. HAProxy, часовой монитор и зарубежные
Xray не перезапускаются. Миграций, новых зависимостей и изменений `.env` нет.
Режим сертификатов «только предупреждать, не блокировать» не меняется.

После установки откройте **Клиенты**, выберите сервер и проверьте колонку
**Подключение**. Если загружена старая версия страницы, выполните полное обновление
в браузере. Для проверки можно подключить известный профиль в своём VPN-приложении
и дождаться обновления 3X-UI/страницы; отключать доступ остальным клиентам не нужно.

на сервере после установки.

# Новости и единая подписка

## Установка на сервере сайта

Архив `vpn-news-account-links-20261030.zip` содержит полные файлы, не diff.
Загрузите архив в `/root` на сервере сайта. Ничего из проекта удалять не нужно.
Не запускайте `git pull` поверх вручную установленных изменений до их сохранения в Git.

Сначала сохраните текущий код, затем распакуйте обновление:

```sh
cd ~/vpnpanel
(
set -e
umask 077
mkdir -p ~/vpnpanel-backups
tar --exclude='./frontend/node_modules' --exclude='./frontend/.next' --exclude='./.git' --exclude='./backups' --exclude='./relay/control' -czf ~/vpnpanel-backups/pre-news-code-$(date +%Y%m%d-%H%M%S).tar.gz .
unzip -o ~/vpn-news-account-links-20261030.zip -d ~/vpnpanel
sh scripts/install-news-account-links.sh
)
```

Продолжайте только если команда создания архива кода завершилась успешно.
Установщик создаёт дамп PostgreSQL в `~/vpnpanel-backups/news-account-links-ДАТА/database.dump`,
проверяет читаемость его оглавления, собирает приложения, запускает тесты,
применяет миграцию `c3d8f102ab67` и перезапускает backend/frontend/Caddy.
VPN relay, его маршруты и серверы 3X-UI не изменяются и не перезапускаются.
Архив кода и дамп содержат приватные данные: не загружайте их в GitHub.

Если установка остановилась, пришлите вывод ошибки. Не удаляйте базу и Docker volumes.
Миграция только добавляет таблицу и колонку, поэтому старый код совместим с новой схемой.
Не выполняйте автоматический `alembic downgrade` для отката приложения.

## Личный кабинет

После обновления отдельные ссылки и QR-коды VPN-серверов скрыты по умолчанию.
Единая подписка, её копирование и QR-код сохраняются.
Карточки серверов показывают статус, трафик и срок доступа.

Для возвращения отдельных VLESS-ссылок:
`Настройки → Личный кабинет → Показывать отдельные ссылки и QR-коды серверов → Сохранить настройки`.
Изменение применяется при следующей загрузке ЛК. Ссылки в административном разделе клиентов не скрываются.

Это упрощение интерфейса, а не запрет извлечения профилей: VPN-приложение должно получить
профили из единой подписки, поэтому технически их можно прочитать из её содержимого.
Подписка по-прежнему выдаёт только оплаченные/предоставленные активные подключения.
Единая ссылка и ранее выданные ссылки не отзываются этой настройкой.

## Новости

В админке откройте `Новости` (`/announcements`), создайте запись и включите `Опубликовать`.
Без этой отметки запись остаётся черновиком. Есть редактирование, закрепление,
снятие с публикации, удаление, поиск и фильтр статуса. Действия записываются в журнал.
Дата публикации задаётся автоматически. При повторной публикации дата обновляется.

Опубликованные новости доступны всем без регистрации на `https://dlgtw.ru/news`.
В шапке публичных страниц есть ссылка `Новости`. Первый элемент ленты отображается
также на странице покупки и в ЛК. Закреплённые записи идут первыми, затем новые.
Пустой блок на покупке и в ЛК скрывается. Содержимое обновляется при загрузке страницы;
на странице новостей есть кнопка обновления.
Текст сохраняется как обычный текст, HTML/скрипты не исполняются.

## Проверка после установки

1. Откройте админку, создайте новость как черновик. В приватном окне `/news` её быть не должно.
2. Опубликуйте запись и обновите `/news` без входа: запись должна появиться.
3. Откройте покупку и ЛК: первая новость должна отображаться.
4. В ЛК должна остаться одна ссылка подписки и её QR, без отдельных VLESS-блоков.
5. Включите настройку отдельных ссылок, сохраните и обновите ЛК: VLESS-блоки вернутся.
6. Обновите единую подписку в VPN-приложении: оплаченные подключения должны сохраниться.
